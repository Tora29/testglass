# アクセシビリティルール（HTML レポート）

## 目標

**WCAG 2.1 レベル AA** を満たす。

- AAA は目標にしない。ただし、デザインを大きく変えずに入るもの（フォーカスの見やすさなど）は、できる範囲で入れる
- レポートはダーク・ライトの両方で表示される。**両方のテーマで**満たす

## 文字の大きさ

WCAG に最小の文字サイズの基準はないが、レビューで長時間読む画面なので、次を下限にする。

| 用途 | 大きさ |
| --- | --- |
| 本文 | 14px（body）を基準にする |
| 操作できる部品（ボタン・絞り込み・セレクト） | 13px 以上 |
| 表の中の文字（手順・期待結果のコード）・補足（ルール ID・行番号・見出しラベル） | 12px 以上 |

- 12px 未満は使わない
- 小さい文字で強弱を付けない。強弱は文字の濃さ（`--ink` 〜 `--ink-3`）と太さで付ける
- 日本語に `letter-spacing` を付けない（字間が空いて読みにくくなる）

## コントラスト（1.4.3 / 1.4.11）

文字色は、背景の上に文字色を透明度で重ねたもの（`--ink` 〜 `--ink-4`）を使う。背景はダーク `#09090d`、ライト `#fafaf9`。

| トークン | ダーク | ライト | 使ってよいもの |
| --- | --- | --- | --- |
| `--ink` / `--ink-2` | 15.99 / 9.72 | 14.82 / 7.29 | すべての文字 |
| `--ink-3`（ダーク 55%・ライト 60%） | 6.26 | 5.07 | すべての文字（補足・日付・ラベルの下限） |
| `--ink-4`（ダーク 25%・ライト 30%） | 2.13 | 2.01 | 飾り（区切りの `·`・開閉の `›`・罫線）のみ。文字には使わない |

- 読む必要のある文字は、補足・番号・ルール ID・行番号・「なし」の表示であっても `--ink-3` 以上にする
- 判定の色（`--error` / `--warn`）とアクセント（`--accent`）は、どちらのテーマでも 4.5:1 以上ある（最も低いのはライトの `--error` で 4.62）。文字に使ってよい。色を変えるときは両方のテーマで 4.5:1 以上あるか確かめる
- 選択中・押された状態は、背景の薄い色だけで示さない。文字色の変化に加えて、3:1 以上ある線（下線・枠）でも示す
- ライトの透明度をダークと同じ値にしない（ライトは同じ透明度でもコントラストが低い）

## キーボード操作（2.1.1 / 2.4.3 / 2.4.7）

- 押せるものは `<button>` か `<a>` にする（`<div>` に `click` を付けない）
- フォーカスの表示を消さない。全体に `:focus-visible` のアウトラインがある。`outline: none` にするときは、代わりに見える印（下線の色など）を付ける
- 絞り込みのボタンは `aria-pressed` で選択状態を伝える
- タブ順は見た目の順と揃える

## 動き（2.3.3）

- `prefers-reduced-motion: reduce` のときは、トランジション・アニメーションを行わない（`styles.css` で一括して止めている）
- 1秒に3回を超えて点滅させない

## 名前・構造（1.3.1 / 2.4.6 / 3.1.1 / 4.1.2）

- アイコンだけのボタン（テーマの切り替えなど）には `aria-label` を付ける
- 見えている文字と `aria-label` を食い違わせない（音声入力で押せなくなるため）
- 1ページに `h1` を1つ置き、見出しのレベルを飛ばさない（ファイル名が `h2`、詳細の見出しが `h3`）
- 複数ある `<nav>` には `aria-label` で区別できる名前を付ける（`判定で絞り込む`、`フレームワークで絞り込む`、`指摘の種類で絞り込む`）
- `<html lang="ja">` を保つ。コード由来の英語（`expect`・`.only` など）に `lang` は付けない

## 確認

- 部品を変えたら、キーボードだけで操作できるか確かめる
- 色を変えたら、上の表のトークンに収まっているか確かめる。表にない色を使うときは、両方のテーマで計算して確かめる
